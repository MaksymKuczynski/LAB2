## 2. Відповідь на контрольне запитання

**Запитання:** `Що таке хвостова рекурсія?`

**Відповідь:**

[Хвостова рекурсія — це спеціальний вид рекурсії, де рекурсивний виклик є останньою операцією перед виходом із функції. Результат цього виклику відразу повертається як результат усієї функції, без додаткових математичних чи логічних дій.

Приклад хвостової рекурсії:
def count_down(n):
    if n == 0:
        return
    print(n)
    count_down(n - 1)
    
count_down(3)

Результат: 3, 2, 1]
